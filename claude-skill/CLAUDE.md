# Thor PSA Validator

This workspace uses the Thor MCP server to validate AWS partner competency applications.

## What Thor does
- Validates partner submissions (Excel checklists + PDFs) against control requirements using Bedrock Claude
- Produces PASS/FAIL/WAIVED verdicts with reasoning for each control
- Supports parallel validation (~49 controls in ~5 minutes), consensus mode, diff between runs, and PDF/HTML export

## MCP tools available
`thor_doctor`, `thor_convert`, `thor_validate`, `thor_run`, `thor_diff`, `thor_prep`, `thor_list_controls`, `thor_export`

## Partner folder structure
```
PartnerName/
├── checklist.xlsx           # Excel checklist (root level)
├── partner_responses.csv    # Generated by thor_convert
├── supporting_docs/         # PDFs, architecture diagrams
├── validation_summary.md    # Latest validation results
└── reports/summary/         # Timestamped archived reports
```

## Key concepts
- **Designation categories** filter which controls apply (e.g., "Generative AI Applications" excludes FM-training controls)
- **Application type** (SERVICE vs SOFTWARE) determines control suffixes
- **Credentials** are auto-discovered from `~/.aws/config` credential_process profiles — no hardcoded keys
- **Consensus mode** runs each control N times and uses majority vote for borderline cases

## Credential refresh
If you see `ExpiredTokenException`, tell the user to run their credential command (`isengardcli assume`, `aws sso login`, etc.) and retry. No server restart needed.
